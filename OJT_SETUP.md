## Git and GitHub basics
- Git tracks changes and maintains commit history.
- GitHub hosts repositories and supports collaboration.
- A fork is a copy of a repository under my GitHub account.
- A clone is a local copy of that repository.
- A branch keeps a set of changes separate from other work.
- A commit records staged changes.
- A push uploads local commits to the remote repository.

## Initial repository workflow
1. Fork the FOSSology repository.
2. Clone my fork locally.
3. Create the `ojt-setup` branch.
4. Add these OJT learning notes.
5. Commit and push the documentation.

## Contribution approach
Read the contribution guidelines, understand the issue, make focused
changes, test them, and respond constructively to review feedback.
